# 内置核心兼容范围

对照本机 Radmin VPN 2.1.2 的 GUI、控制服务和组网引擎分析记录，以及官方帮助。官方软件的 Windows 集成和远程管理有各自的运行条件。

| 功能 | 内置核心覆盖 |
| --- | --- |
| 注册和复用设备身份 | 支持。保存虚拟 IPv4 和已有网络成员身份。 |
| 网络管理 | 支持创建私网、加入网络、查询公共目录、启用、停用、退出、删除和管理员移除成员。管理员授权和撤销已在官方服务通过验证。审批已通过本地协议测试，等待官方服务的真实审批请求做端到端验证。改密仍需补齐。 |
| 名称、在线状态和连接 | 支持提交昵称、接收改名事件、显示已知在线状态和连接方式。活动对端通道可提供延迟。官方客户端右键发起的通用 Ping 仍需补齐。 |
| Minecraft 入站与出站 | 支持通过内置核心加入房间和对外开房。开房端使用「对局域网开放」，内核只转发该游戏端口。两个独立内核实例通过官方协调服务验证了双向发现、状态查询和 Ping。 |
| 系统 VPN | CLI 和系统适配器支持授权对端的 IPv4 流量。不同操作系统仍有独立的网卡配置和权限要求。完整的二层广播、任意应用、Windows 防火墙集成和移动端真机兼容仍待验证。 |
| Radmin 集成 | 官方 VPN 菜单中的远程桌面需要独立的 Radmin Server。聊天、文件传输和远程桌面集成尚未移植。 |

游戏内和系统 VPN 的使用方法见[内置核心指南](core-integration.md)。
