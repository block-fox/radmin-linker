# Radmin Linker

![Radmin Linker](docs/radmin-linker-cover.png)

[English](README.md) · [简体中文](README.zh-CN.md) · [Tiếng Việt](README.vi.md) · **Русский** · [Українська](README.uk.md) · [日本語](README.ja.md)

Radmin Linker — клиентский мод Fabric для подключения к Radmin VPN и управления им прямо в Minecraft. Поддерживаются версии Minecraft **26.3, 26.2, 1.21.11 и 1.21.1**. Скачайте JAR для своей версии игры на странице [релизов GitHub](https://github.com/block-fox/radmin-linker/releases). Список изменений приведён в [журнале версий](CHANGELOG.md).

## Установка и интеграция

- **Radmin Linker отдельно** предоставляет вкладки сетей, пользователей, заблокированных пользователей и настроек. Установите также Fabric API. Обычная сборка использует официальную службу Windows. В автоматическом режиме сборка `-core.jar` использует официальную службу, если та доступна при запуске на Windows. В остальных случаях используется встроенное ядро. См. [руководство по встроенному ядру на китайском](docs/core-integration.md).
- **LanWorlds отдельно** добавляет в стандартный список локальных игр значки, MOTD, адреса, число игроков, задержку и правила блокировки. См. [LanWorlds](https://github.com/block-fox/LanWorlds).
- **Оба мода вместе** показывают сведения о пользователе Radmin, сети и соединении для соответствующих локальных игр. Оттуда можно открыть свойства пользователя и сети. Оба мода должны быть собраны для одной версии Minecraft. Интеграция доступна в Radmin Linker 1.0.1 и LanWorlds 1.0.2.

Перед обновлением с RadminLAN удалите старый JAR. Если нового файла настроек ещё нет, Radmin Linker при запуске прочитает `config/radminlan.json` и сохранит настройки в `config/radminlinker.json`.

## Возможности

- Восемь режимов отображения сетей и пользователей, сортировка, фильтры и множественный выбор. При открытии списка участников сети её фильтр применяется автоматически.
- Для пакетных операций видно число успешных и неудачных действий. Неудавшиеся действия можно повторить. Автообновление сохраняет сообщение о результате.
- В верхней части окна управления можно сменить имя пользователя и включить или выключить VPN. Перед отключением запрашивается подтверждение.
- Сети, пользователи и измеренная задержка считываются через управляющий канал службы Windows. Настроенный CLI может служить резервным способом запросов.
- Наведите указатель на значок состояния, чтобы увидеть подробности. При включённом автообновлении данные службы о присутствии и задержке поступают в интерфейс каждые два игровых такта. Полные запросы обновляют сведения о сетях и участниках с интервалом от 1 до 60 секунд. До получения измерения задержка неизвестна, а через 60 секунд измерение устаревает.
- В небольшом окне списки, настройки и свойства можно прокручивать. Настройки открываются из Mod Menu или меню сетевой игры.

## Разработка

Minecraft 26.2 и 26.3 используют общий исходный код в корне проекта и JDK 25. Версии 1.21.11 и 1.21.1 используют JDK 21 и общий код серверного взаимодействия и конфигурации. Запускайте клиент разработки скриптом для нужной версии.

```powershell
./scripts/run-26.3.ps1 -JavaHome '<JDK 25 path>' -Online
./scripts/run-26.2.ps1 -JavaHome '<JDK 25 path>' -Online
./scripts/run-1.21.11.ps1 -JavaHome '<JDK 21 path>' -Online
./scripts/run-1.21.1.ps1 -JavaHome '<JDK 21 path>' -Online
```

Для сборки используйте соответствующий скрипт `scripts/build-*.ps1`. Результаты сборки находятся в `versions/<minecraft-version>/build/`. Перед сборкой или сменой версии закройте клиент разработки. Если зависимости уже в кэше, параметр `-Online` можно опустить. В обычной копии репозитория используйте общедоступные зависимости вместо необязательной локальной среды 26.3.

```powershell
./gradlew.bat classes -Puse_local_runtime=false
```

Запускайте регрессионные проверки с JDK для выбранной версии. Для 26.2 также передайте свойства из `versions/26.2/gradle.properties` как аргументы `-P`.

```powershell
./gradlew.bat -I tests/regression.init.gradle uiRegressionCheck --no-configuration-cache
./gradlew.bat -p versions/1.21.11 -I ../../tests/regression.init.gradle uiRegressionCheck --no-configuration-cache
./gradlew.bat -p versions/1.21.1 -I ../../tests/regression.init.gradle uiRegressionCheck --no-configuration-cache
```

Проверки охватывают ввод, перенос настроек, фильтры, компоновку, частичные сбои пакетных операций, резервный CLI, сопоставление IPv6 и телеметрию. Если установлен Radmin VPN, запустите `nativeTelemetrySmoke`, чтобы проверить начальное чтение и дальнейшие уведомления по подписке. Документация на китайском языке включает [описание телеметрии](docs/telemetry-protocol.md), [руководство по интеграции с LanWorlds](docs/lanworlds-integration.md) и [руководство по разработке](docs/development.md).
